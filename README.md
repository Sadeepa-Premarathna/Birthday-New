# Happy Birthday Sudu 💖

A romantic, interactive birthday surprise website built with love for **Sudu**.

## ✨ Features
- 🎁 **Surprise Entrance Box**: Tap to open with sweet chimes and confetti explosion.
- 🎶 **Happy Birthday Melody**: Plays using Web Audio API (100% reliable, zero external MP3 dependency required, no broken audio links).
- 👑 **"Happy Birthday Sudu" Hero**: Glowing 3D typography, animated calligraphy, and floating crown.
- 🎂 **Interactive Cake**: Tap the candle to blow it out and make a wish (includes candle smoke and burst celebration).
- 💌 **Love Letter**: Romantic heartfelt note card.
- 💖 **Love Counter Button**: Sends floating hearts and sound chimes with every tap.
- 🎈 **Balloons & Confetti**: Realistic floating pastel balloons and sparkling fireworks.

## 🚀 How to Deploy on Vercel

### Option 1: Using Vercel CLI (Super Fast)
1. Open PowerShell / Terminal in this folder (`d:\Birthday`).
2. Run:
   ```bash
   npx vercel
   ```
3. Follow the simple prompts (press Enter for default settings).
4. Your website will be live in seconds!

### Option 2: Using GitHub + Vercel Dashboard
1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **Add New Project** -> Select your GitHub repository.
4. Leave settings as default and click **Deploy**!
